墨迹剧场

A STUDY OF FORMAT IN INK

中国画从来不只是一幅画，而是一种观看方式。
形制决定视线如何移动——立轴自上而下，长卷自右而左，团扇绕心而行，山势自峰而落。

展卷
一

立轴

VERTICAL SCROLL

立于墙前，目光自上而下，一泻千里。立轴把时间竖起来。

1.1用途
书画装裱 / 中堂悬挂 / 条幅对联
1.2形制
狭长纵幅 / 天地头 / 绫边 / 轴杆
1.3气韵
高远 / 收束 / 纵势 / 凝神
1.4章法
居中取势 / 上下留白 / 一线贯穿
二

长卷

HORIZONTAL HANDSCROLL

展一寸，看一寸；收起，便是一轴无言的记事。长卷不给人全景，它只给「下一段」。

2.1用途
案头展观 / 题跋接续 / 卧游 / 叙事
2.2形制
横幅 / 引首 / 拖尾 / 接纸
2.3气韵
平远 / 舒展 / 从容 / 移步换景
2.4章法
起承转合 / 长轴贯通 / 留白呼吸

变体 · 册页

Rounded

同样的横势，四角一圆，便从堂皇转为温润。册页可收可展，像把一段山水折进衣袋。

变体 · 屏风

Folded

折页成屏，形制自己长出棱角。每一扇各成一幅，合起来又是一幅。

三

团扇

CIRCULAR FAN

一握之间，山水收拢成圆。团扇不追求深远，它只求把一方小景，端端正正地放在掌心。

3.1用途
手持扇面 / 赠答 / 小景 / 花鸟
3.2形制
圆形 / 绢本 / 竹柄 / 双面
3.3气韵
圆满 / 精致 / 亲近 / 团圆
3.4章法
中心取势 / 边角留白 / 环形呼应
四

山势

TRIANGULAR / FOLDING FAN

折扇一开，山便立起来。三角是最不肯安分的形制——它总要往一个方向倒。

4.1用途
折扇扇面 / 险景 / 屏障 / 远景
4.2形制
三角 / 斜向 / 折线 / 尖锐
4.3气韵
峻拔 / 动势 / 奇险 / 凌厉
4.4章法
对角取势 / 上重下轻 / 峰峦叠压
